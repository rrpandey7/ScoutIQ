# 🏀 ScoutIQ

ScoutIQ is an AI-powered NBA analytics platform built with Python and Streamlit.

## Features

- 🔍 Player Similarity Search
- 📊 ScoutIQ Player Ratings
- 🏀 Team Analyzer
- 🔄 Trade Analyzer
- 💰 Free Agent Finder
- 🤖 GM Assistant
- 📈 Interactive Visualizations

## Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-Learn
- Plotly
- NBA API
